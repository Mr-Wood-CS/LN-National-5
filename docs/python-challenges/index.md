# Python Programming Challenges

Practise your Python skills with these 98 challenges. Work through the sections in order, or start where your teacher asks you to. The collection includes the original challenges and 54 adapted from Lochaber High School's *Python Programming Challenges* booklet.

## What will you practise?

- **Input/Output: Challenges 1–19.**
- **Working with Numbers: Challenges 20–32.**
- **Selection [If, Elif, Else]: Challenges 33–64.**
- **Fixed Loops: Challenges 65–75.**
- **Conditional Loops: Challenges 76–82.**
- **Arrays: Challenges 83–89.**
- **Built-in Functions and String Tools: Challenges 90–98.**

## What to do

1. Read **Your task**, **What to enter** and **What your program should show**.
2. Read **Python tools you may need** before starting, especially if a tool is new to you. Try its small examples first.
3. Make a plan using the method your teacher has shown you, then write your program.
4. Save each program using its current challenge number, such as `challenge_1.py`.
5. Open **Show a hint** if you need a nudge. The **Need a hand?** links offer more help.
6. Use **Try your program**. Run once for each test row, type the supplied information and compare your result with **You should see**.
7. Tick matching tests in your workbook. If a result does not match, check your code and try again.

## A few helpful reminders

- A whole number has no decimal part. Some tasks allow negative numbers.
- Keep the stated input order and output spelling, spaces and line breaks.
- Only print the messages requested. Do not add input prompts unless asked.
- Most tasks assume valid input. The input-checking tasks tell you which entries to reject and how to ask again.
- Random games do not always produce the same result. Their test instructions give fixed choices to use temporarily while checking. Restore randomness afterwards.
- Tables give results for the supplied tests, not finished programs or solution steps.
