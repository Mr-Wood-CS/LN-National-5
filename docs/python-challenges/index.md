# Python Programming Challenges

Practise your Python skills with these 44 challenges. Start at Challenge 1 and work through them in order, unless your teacher asks you to start somewhere else.

## What will you practise?

- **Challenges 1–7:** entering information, doing calculations and showing results.
- **Challenges 8–20:** working with digits, money, time and other numbers.
- **Challenges 21–44:** making decisions in your programs.

## What to do

1. Read **Your task** to find out what your program needs to do.
2. Make a plan using the method your teacher has shown you.
3. Write your Python program. Save it with a name such as `challenge_1.py` so you can find it again.
4. Read **What to enter** and **What your program should show**. These tell you what to type and what your program needs to display.
5. Use **Try your program** to check it. Each challenge has a table of values to type and the results you should see, taken from the original challenge's test files.
6. Run your program once for each row in the table. Compare your result with **You should see**, and tick the test in your workbook when it matches.
7. If a result does not match, check your code, make a change and try that test again.

## A few helpful reminders

- A **whole number** has no decimal part. Some tasks allow negative numbers, such as numbers below zero.
- When asked for more than one number, type them in the order listed. Press Enter after each one.
- Copy the spelling, capital letters, spaces and line breaks shown in the task. Only add extra words if the task asks for them.
- You can assume the information entered follows the task's rules. You do not need to add checks for someone typing the wrong kind of information.
- If you get stuck, use the **Need a hand?** links on the challenge page. You can read a lesson or work through it one small step at a time, then ask your teacher if you still need help.
- The tables show the results for the supplied tests. They do not give you the Python code or steps for solving the challenge.
