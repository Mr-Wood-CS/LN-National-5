# Area of a circle

## Your task

Calculate the area of a circle in square centimetres. Use 3.14 for pi. Circle area is pi multiplied by the radius multiplied by the radius.

## What to enter

One positive number: the radius in centimetres. Decimal measurements are allowed. Type each value on a separate line, pressing Enter after each one.

## What your program should show

Show `The area of the circle is:` on one line, then the area followed by ` square centimetres` on the next. Do not round deliberately; a whole-number answer may include `.0`.

Only show the results and messages described above. Do not add input prompts; the tables below show the information to type.

## Python tools you may need

Try the small examples first if a tool is new to you. These tools are not a finished solution.

- **`input()` — read what someone types.** It gives you text, even when the person types digits.
- **`float()` — turn text into a number that can have a decimal part.** For example, `float("2.5")` gives the number `2.5`.
- **`print()` — show a result.** Each separate `print()` starts a new output line. To show two values on one line with a space between them, put a comma between them inside `print()`.
- **`*` — multiply numbers.** For example, `6 * 4` gives `24`. Python uses `*`, rather than the multiplication sign you may use on paper.
- **f-strings — put a value inside a message.** Put `f` before the opening quotation mark and a variable inside curly brackets. For example, `f"Score: {score}"` inserts the value stored in `score`.

## Hint

??? tip "Show a hint"

    Make sure the entered measurement is the radius, from the centre to the edge, rather than the full width of the circle.
