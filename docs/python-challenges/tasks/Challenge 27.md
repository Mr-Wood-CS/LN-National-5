# Four-digit palindrome

## Your task

Write a Python program for this task.

A palindrome reads the same forwards and backwards. Check whether a four-digit number is a palindrome.

## What to enter

One whole number from 1000 to 9999 (including both ends). Type each number on a new line, pressing Enter after each one.

## What your program should show

Show `YES` for a palindrome; otherwise `NO`.

Only show the result described above. Do not add extra words such as "Enter a number" or "The answer is" unless this task asks for them.

Use capital letters for these messages.

## Hint

??? tip "Show a hint"

    Write the four digits in boxes and read them in both directions. Think about which positions need to match. Checking only the two outside digits is not enough.

Use the tests below to check your program. You do not need to make up your own numbers.

1. Run your program.
2. Type the values in the middle column, one at a time. Press Enter after each line.
3. Compare your result with the last column. It should match.
4. If it matches, tick that test in your workbook. If it does not, check your code and try again.
5. Run your program again for the next test.
