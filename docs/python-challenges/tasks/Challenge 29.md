# Challenge 29: Days in a month

## Your task

Write a Python program for this task.

Report the days in a month of 2017, a non-leap year. January, March, May, July, August, October and December have 31 days; April, June, September and November have 30; February has 28.

## What to enter

One month number from 1 (January) to 12 (December). Type each number on a new line, pressing Enter after each one.

## What your program should show

One whole number: days in that month.

Only show the result described above. Do not add extra words such as "Enter a number" or "The answer is" unless this task asks for them.
