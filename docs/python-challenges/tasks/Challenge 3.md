# Challenge 3: Personal greeting

## Your task

Write a Python program for this task.

Read a person's name and greet them.

## What to enter

One line of text containing the complete name; preserve spelling and capitalisation. Type the full name on one line, then press Enter.

## What your program should show

One line in the format `Hello, NAME!`, replacing NAME with the name entered. Include one space after the comma and none before the exclamation mark.

Only show the result described above. Do not add extra words such as "Enter a number" or "The answer is" unless this task asks for them.

## Try your program

Use the tests below to check your program. You do not need to make up your own names.

1. Run your program.
2. Type the full name in the middle column, including any spaces. Then press Enter.
3. Compare your result with the last column. It should match.
4. If it matches, tick that test in your workbook. If it does not, check your code and try again.
5. Run your program again for the next test.

Where a table cell has several lines, keep the same line breaks when typing or comparing the result.
