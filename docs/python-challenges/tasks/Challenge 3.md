# Personal greeting

## Your task

Write a Python program for this task.

Read a person's name and greet them.

## What to enter

One line of text containing the complete name; preserve spelling and capitalisation. Type the full name on one line, then press Enter.

## What your program should show

One line in the format `Hello, NAME!`, replacing NAME with the name entered. Include one space after the comma and none before the exclamation mark.

Only show the result described above. Do not add extra words such as "Enter a number" or "The answer is" unless this task asks for them.

## Python tools you may need

These are tools you can use, rather than the steps for solving the task. The small examples use different information from the challenge.

- **`input()` — read what someone types.** It gives you text, even when the person types digits.
- **Variables — keep information for later.** For example, `score = 8` stores a value using the name `score`. A single `=` stores a value; it does not compare two values.
- **`print()` — show a result.** Each separate `print()` starts a new output line. To show two values on one line with a space between them, put a comma between them inside `print()`.
- **Text and `+` — join pieces of writing.** Text goes inside quotation marks. For example, `"Good" + " morning"` gives `Good morning`. Spaces must be included where you want them.

## Hint

??? tip "Show a hint"

    Write the greeting on paper with a blank space for the name. Look carefully at where the comma, space and exclamation mark belong. The name might contain a space of its own.
