# Challenge 25: Exactly one positive number

## Your task

Write a Python program for this task.

Check whether exactly one of two whole numbers is positive. If both numbers are positive, or both are negative, the answer is NO.

## What to enter

Two whole numbers. Neither number can be zero. Type each number on a new line, pressing Enter after each one.

## What your program should show

Show `YES` if exactly one is positive; otherwise `NO`.

Only show the result described above. Do not add extra words such as "Enter a number" or "The answer is" unless this task asks for them.

Use capital letters for these messages.
