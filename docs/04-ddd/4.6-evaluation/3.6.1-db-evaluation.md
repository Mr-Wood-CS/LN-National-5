# Evaluating a Database Solution

National 5 database evaluation looks at **fitness for purpose** and **accuracy of output**. Use the requirement and evidence from the query result to support each judgement. [National 5 specification, Appendix 8](https://www.sqa.org.uk/sqa/files_ccc/n5-course-spec-computing-science.pdf#page=63)

## Worked example

The [Bakery query design](../4.3-design/3.3.3-query-design/3.3.3-query-design.md) requires the product name, price and bakery name for Glasgow products costing under £2. The [test results](../4.5-testing/3.5.1-db-testing.md) show which rows and fields appeared and in what order.

| Criterion | Evidence-based judgement |
| --- | --- |
| **Fitness for purpose** | The query finds the three qualifying products and lists the cheapest first. It places Empire biscuit before Oat biscuit when their prices tie, as required. |
| **Accuracy of output** | Each row shows the required product name, the correct price and the correct bakery. For example, Empire biscuit appears at 120 pence from Park Bakery. |

A query can select the correct records and still have incomplete output. If `BakeryName` were omitted from `SELECT`, the filters and sort order would still work, but the result would be missing a requested field. Add `Bakery.BakeryName` to the field list and rerun the test.
