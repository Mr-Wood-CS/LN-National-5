# SQL INSERT Operations

## What is INSERT?

`INSERT` adds a record. The following examples form a sequence on a copy of the [Bakery database](bakery-database.md). Insert Shortbread, update its price, then delete its record. The original five products remain available for the query and testing examples.

## Worked example

```sql
INSERT INTO Product (ProductID, ProductName, PricePence, BakeryID)
VALUES (106, 'Shortbread', 110, 1);
```

The values must match the order of the named fields. Bakery 1 already exists, so the foreign key is valid.
