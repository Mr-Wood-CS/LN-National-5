# SQL Equi-Join Operations

## What Is An Equi-Join?

An equi-join matches records from two tables using an equality comparison. In the [Bakery database](bakery-database.md), `Product.BakeryID` contains the bakery identifier, and the matching `Bakery` record contains its name and town.

```sql
SELECT Product.ProductName, Bakery.BakeryName
FROM Product, Bakery
WHERE Product.BakeryID = Bakery.BakeryID;
```

Use `TableName.FieldName` when the same field name appears in both tables. The equality condition matches each product to its bakery. Leaving out the condition would pair each product with every bakery.

## Filtering and sorting joined results

The [query design](../4.3-design/3.3.3-query-design/3.3.3-query-design.md) calls for the product, price and bakery name for Glasgow products costing under £2. It sorts by price, then by product name.

```sql
SELECT Product.ProductName, Product.PricePence, Bakery.BakeryName
FROM Product, Bakery
WHERE Product.BakeryID = Bakery.BakeryID
  AND Bakery.Town = 'Glasgow'
  AND Product.PricePence < 200
ORDER BY Product.PricePence ASC, Product.ProductName ASC;
```

The first condition links the two tables. The other conditions filter the joined records. `Town` is needed for filtering even though it is absent from the output.
