# SQL SELECT Operations

These examples use the records in the [Bakery database](bakery-database.md).

## SELECT ... FROM ...

`SELECT` specifies the fields to display. `FROM` names the table. Use `*` to display all fields.

```sql
SELECT ProductName, PricePence
FROM Product;
```

## SELECT ... FROM ... WHERE ...

`WHERE` filters records. Use `=` for an exact match, `<` for less than, and `>` for greater than. Put text values in single quotes, such as `Town = 'Glasgow'`. Numeric values such as `120` go without quotes.

```sql
SELECT ProductName, PricePence
FROM Product
WHERE PricePence < 120;
```

This returns Morning roll and Fruit scone. Both biscuits cost exactly 120 pence, so they are excluded.

## AND and OR

`AND` requires both conditions to be true. This query finds products from bakery 1 that cost less than 120 pence.

```sql
SELECT ProductName
FROM Product
WHERE BakeryID = 1 AND PricePence < 120;
```

`OR` requires at least one condition to be true. This query returns bakeries in either town.

```sql
SELECT BakeryName
FROM Bakery
WHERE Town = 'Glasgow' OR Town = 'Greenock';
```

## ORDER BY

`ASC` sorts smallest to largest or A to Z. `DESC` reverses that order. With two fields, the second field breaks ties in the first.

```sql
SELECT ProductName, PricePence
FROM Product
ORDER BY PricePence ASC, ProductName ASC;
```

Empire biscuit and Oat biscuit both cost 120 pence. Empire biscuit appears first because the second field sorts the tied products alphabetically.
