# SQL DELETE Operations

## What is DELETE?

`DELETE` removes existing records. The following examples form a sequence on a copy of the [Bakery database](bakery-database.md). Insert Shortbread, update its price, then delete its record. The original five products remain available for the query and testing examples.

## Worked example

```sql
DELETE FROM Product
WHERE ProductID = 106;
```

The primary key identifies the Shortbread record. Without the WHERE clause, all product records would be removed.
