# SQL UPDATE Operations

## What is UPDATE?

`UPDATE` changes fields in existing records. The following examples form a sequence on a copy of the [Bakery database](bakery-database.md). Insert Shortbread, update its price, then delete its record. The original five products remain available for the query and testing examples.

## Worked example

```sql
UPDATE Product
SET PricePence = 125
WHERE ProductID = 106;
```

The primary key identifies the Shortbread record. Without the WHERE clause, every product's price would change.
