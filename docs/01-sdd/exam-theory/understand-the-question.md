# Understand the question

**Your focus:** Turn the instruction into a short checklist.

Read the instruction before you read the code. Underline what your answer must contain.

| If the question asks you to… | Your answer needs… | Avoid… |
| --- | --- | --- |
| **State** a value or output | The requested value or exact output | Describing the whole program |
| **Describe** what happens | A clear account of the relevant steps | Only naming a programming construct |
| **Explain** a result or error | What the code does and why that produces the result | “It does not work” without a reason |
| **Write** code or an algorithm | All the requested steps in the requested notation | Explaining your idea without supplying code |
| **Identify and correct** an error | The error and a suitable correction | Pointing out the error without fixing it |

!!! example "Translate the task"
    **Task:** “Write an algorithm that inputs five scores and displays their total.”

    Your checklist is: initialise a total, input a score five times, add each score to the total, then display the final total.
