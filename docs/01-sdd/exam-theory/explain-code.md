# Explain code

**Your focus:** Link an instruction to its effect using evidence.

Use this structure when you need to explain a result:

> **The instruction…** changes **this value…**, so **this result happens…**.

| Too vague | A clearer explanation |
| --- | --- |
| “It adds the numbers.” | “Line 4 adds each input score to `total`, so the total includes all three scores.” |
| “The loop is wrong.” | “The input is outside the loop, so an invalid locker number is never replaced and the stopping condition stays false.” |
| “The condition is incorrect.” | “Using `> 25` excludes an order worth exactly £25. Use `>= 25` to include the free-postage boundary.” |

Use the variable names, values and line numbers from the actual question. A line number helps locate the evidence; explain what that line does as well.
