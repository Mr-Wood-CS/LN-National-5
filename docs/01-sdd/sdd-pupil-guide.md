# Answering Code Questions

Practise one skill at a time. Start with the first section if you are new to coding questions, or choose the skill you need to revise.

!!! tip "When you feel stuck"
    **Find the input → track the changes → check the condition → write the output.**

    Start with one value or one pass through a loop.

## How to use these pages

Read one example, try the question yourself, then open the answer to check your thinking. Move on when you can explain the method in your own words.

## Before you move on

!!! tip "Check your answer against the task"
    - **Output:** Have I written exactly what is displayed, in the right order?
    - **Values:** Did I use each variable’s latest value?
    - **Conditions:** Did I check the boundary and distinguish AND from OR?
    - **Loops:** Did I count the passes and check where input, initialisation and output happen?
    - **Explanation:** Did I connect the code to its effect using the actual values?
    - **Written code:** Have I included every requested input, process and output?
