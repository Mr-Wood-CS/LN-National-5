## What Is a Fixed Loop?

**Iteration** means repeating a set of instructions. One pass through those instructions is called an **iteration**.

A **fixed loop**, also called a **count-controlled loop**, repeats a block of instructions a set number of times. The program knows the number of repetitions when the loop starts. For example, a quiz with five rounds can use a fixed loop to display one heading per round.

## Designing a Fixed Loop

This pseudocode shows what happens during each round and what happens after all five rounds.

```pseudocode title="Quiz Round Design" linenums="1"
FOR round_number FROM 1 TO 5
    DISPLAY "Round", round_number
END FOR
DISPLAY "Quiz complete"
```

In this design, the counter starts at 1 and ends at 5, inclusive. The final message is outside the loop, so it is displayed once.

## Implementing a Fixed Loop in Python

```python title="Quiz Rounds" linenums="1"
for round_number in range(1, 6):
    print("Round", round_number)

print("Quiz complete")
```

- The first line starts the loop. The colon marks the start of the block.
- `range(1, 6)` supplies the values 1, 2, 3, 4 and 5. Python leaves out the stop value, 6.
- `round_number` is the **loop counter**. Python gives it the next value automatically at the start of each iteration.
- The indented `print()` runs once per iteration. The final `print()` lines up with `for`, so it runs once after the loop finishes.

### Tracing the Counter and Output

| Iteration | Value of `round_number` | Output |
| --- | --- | --- |
| 1 | 1 | Round 1 |
| 2 | 2 | Round 2 |
| 3 | 3 | Round 3 |
| 4 | 4 | Round 4 |
| 5 | 5 | Round 5 |
| After the loop | | Quiz complete |

The output has six lines, even though the loop runs five times. The last line comes from the instruction after the loop.

## Choosing the Values in a Range

| Python expression | Counter values | Iterations |
| --- | --- | --- |
| `range(5)` | 0, 1, 2, 3, 4 | 5 |
| `range(1, 6)` | 1, 2, 3, 4, 5 | 5 |
| `range(3, 7)` | 3, 4, 5, 6 | 4 |
| `range(3, 3)` | No values | 0 |

With one argument, `range()` starts at zero. With two arguments, the range starts at the first value and stops before the second. For a range that counts up by one, subtract the start from the stop to find the number of iterations when the stop is greater than the start.

A counter value can differ from the number of times the body has run. In `range(3, 7)`, the counter is 3 on the **first** iteration.

## Using a Fixed Loop to Collect Input

A coach records the points from a known number of games. The user enters the number of games before the loop begins, so the program can determine how many scores to ask for.

```python title="Total Points" linenums="1"
game_count = int(input("How many games were played? "))
total_points = 0

for game_number in range(1, game_count + 1):
    print("Game", game_number)
    points = int(input("Enter the points scored: "))
    total_points = total_points + points

print("Total points:", total_points)
```

This example assumes that the user enters a non-negative whole number for the game count and a whole number for each score. If there are three games, `range(1, game_count + 1)` becomes `range(1, 4)`. The program asks for three scores.

| Game | Points entered | Total after adding the points |
| --- | --- | --- |
| 1 | 4 | 4 |
| 2 | 0 | 4 |
| 3 | 7 | 11 |

This is a **running total**, one of the National 5 standard algorithms. The program sets the total to zero **before** the loop, adds each score **inside** the loop and displays the result **after** the loop.

## Common Errors

- **Stopping one iteration early.** `range(1, 5)` supplies 1 through 4. Use `range(1, 6)` to include 5.
- **Putting the final output inside the loop.** Indenting the final `print()` in the points example displays a partial total after each score.
- **Resetting the total on every iteration.** If `total_points = 0` is placed inside the loop before the addition, each score replaces the previous total.

Use a [conditional loop](5.7_Conditional_Loops_%28while%29.md) when the program must keep repeating until a condition changes, such as when a user enters a valid value.
