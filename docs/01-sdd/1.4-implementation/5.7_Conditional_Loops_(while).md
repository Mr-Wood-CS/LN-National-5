## What Is a Conditional Loop?

A **conditional loop** uses a condition to decide whether to repeat a block of instructions. A Python `while` loop checks that condition **before** each iteration.

1. If the condition is true, the program runs the indented instructions.
2. At the end of the body, the program returns to the condition and checks it again.
3. If the condition is false, execution continues at the first instruction after the loop.

If the first check is false, the body runs **zero times**. A condition in an `if` statement is checked once each time execution reaches the statement. A `while` loop returns to the condition after each completed iteration.

## Designing a Conditional Loop

A program accepts the word `ready` before it starts. The number of attempts depends on what the user enters.

```pseudocode title="Wait Until the User Is Ready" linenums="1"
GET response FROM USER
WHILE response is not "ready"
    GET response FROM USER
END WHILE
DISPLAY "Starting"
```

The first input gives the program a value to check. The input inside the loop replaces that value so the next check uses the latest response.

## Implementing a Conditional Loop in Python

```python title="Wait Until the User Is Ready" linenums="1"
response = input("Type ready to begin: ")

while response != "ready":
    response = input("Type ready to begin: ")

print("Starting")
```

The comparison `response != "ready"` means “the response is different from `ready`”. That is the condition for **repeating**. The program leaves the loop when the response is `ready`.

| Response at the check | Result of `response != "ready"` | What happens next |
| --- | --- | --- |
| `wait` | True | Prompt again inside the loop. |
| `almost` | True | Prompt again inside the loop. |
| `ready` | False | Leave the loop and display `Starting`. |

In this trace, the condition is checked three times and the loop body runs twice. If the first response is `ready`, there is one check and the body is skipped.

## Input Validation With a Range Check

Input validation checks whether the data entered meets the program's rules. A mark must be a whole number from 0 to 100 inclusive. This example assumes the user enters a whole number each time and checks whether that number is within the permitted range.

```python title="Validate a Mark" linenums="1"
mark = int(input("Enter a whole-number mark from 0 to 100: "))

while mark < 0 or mark > 100:
    print("The mark must be from 0 to 100.")
    mark = int(input("Enter a whole-number mark from 0 to 100: "))

print("Mark accepted.")
```

The condition uses `or` because **either** comparison is enough to reject the mark. A mark cannot be below 0 and above 100 at the same time. Both 0 and 100 make the condition false, so the program accepts both endpoints.

| Test data type | First mark entered | Expected behaviour |
| --- | --- | --- |
| Normal | 50 | Accept the mark straight away. |
| Extreme | 0 or 100 | Accept either endpoint straight away. |
| Exceptional | -1 or 101 | Display an error and ask for another mark. |

For the input sequence `101`, `-1`, `100`, the loop body runs twice. Each time, the user sees an error and can enter a replacement. The program then accepts 100 and displays the confirmation once.

## Common Errors

- **Checking for a valid value in the loop header.** The range-check loop needs to repeat for an invalid mark. Using `while mark >= 0 and mark <= 100:` would repeat for valid marks and skip the loop for invalid ones.
- **Leaving out the update.** Without the second input, an invalid mark stays the same. The condition remains true and the program keeps printing the error. This is an **infinite loop**.
- **Indenting the confirmation.** The confirmation belongs after the loop. Inside the body, it could be displayed during a retry before the replacement value has been checked.

## Choosing Between Fixed and Conditional Loops

| Requirement | Suitable loop | Reason |
| --- | --- | --- |
| Ask for exactly five marks. | [Fixed loop](5.6_Fixed_Loops_%28for%29.md) | The number of inputs is known before the loop starts. |
| Ask again until one mark is in range. | Conditional loop | The number of retries depends on what the user enters. |

A program that collects five valid marks can use both patterns. The fixed loop controls how many marks to collect, and a conditional loop checks each mark before the program moves on to the next one.
