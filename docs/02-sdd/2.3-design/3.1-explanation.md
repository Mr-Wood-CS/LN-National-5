# Design

Design turns the requirements from analysis into a plan for the data, algorithm and user interface.

!!! info "What you need to know"

    - Choose suitable data types and structures for the problem.
    - Recognise, describe and interpret structure diagrams, flowcharts and pseudocode. Use a suitable technique to plan a solution.
    - Use a wireframe to plan the program's inputs and outputs.

## What you plan

| Part of the solution | Design decision |
| --- | --- |
| Data | Identify the values the program needs to store, then choose their types and decide whether related values belong in a structure such as a one-dimensional array. [Data Types and Structures](3.2-data-types-and-structures.md) |
| Algorithm | Break the problem into tasks with a structure diagram, show the order and decisions with a flowchart, or express the steps in pseudocode. [Design Notation](3.3-design-notation-explanation.md) |
| User interface | Plan what the user enters, how they start the calculation and where they see the result. [Design a program interface](3.7-wireframes.md) |
