# Traversing an Array

!!! info "What you need to know"

    You must be able to describe, exemplify and implement the standard algorithm for traversing a one-dimensional array.

## What does traversing an array mean?

To **traverse** an array means to access each element in turn, from the first element to the last.

A loop can use a counter to access each element. The counter matches the element's index.

For example, this array has seven elements. Their indexes are `0` to `6`.

!!! info "The steps in the algorithm"

    ```text
    FOR counter FROM 0 TO 6 DO
        SEND array[counter] TO DISPLAY
    END FOR
    ```
    The loop uses the counter to access each element in the array and display it.

## Two ways to traverse an array with a for loop

Both examples use a `for` loop. You can set the end of the range with a fixed number or calculate it with `len()`.

!!! example "The Snow White Program"

    === "Code"

        ```python linenums="1"
        names = ["Dopey", "Grumpy", "Doc", "Bashful", "Sneezy", "Sleepy", "Happy"]

        for counter in range(0, 7):
            print(names[counter])
        ```

    === "Explanation"

        **Line 1**

        The `names` array stores seven names. The indexes are `0` to `6`.

        **Line 3**

        The loop sets `counter` to each value from `0` to `6`. In Python, the final value in `range()` is not included, so `range(0, 7)` gives the counter values `0`, `1`, `2`, `3`, `4`, `5` and `6`.

        **Line 4**

        `names[counter]` accesses the element at the index held in `counter`. The `print` statement displays that name.

        The loop repeats until every name has been displayed.

!!! example "The Snow White Program using `len()`"

    ```python linenums="1"
    names = ["Dopey", "Grumpy", "Doc", "Bashful", "Sneezy", "Sleepy", "Happy"]

    for counter in range(len(names)):
        print(names[counter])
    ```

    `len(names)` gives the number of elements in the array. Here it gives `7`. With one argument, `range()` starts at `0` and stops before that argument, so `range(len(names))` is equivalent to `range(0, len(names))`.

    If you add or remove names, the loop uses the new length automatically and still visits every element.

!!! tip "Remember"

    The name `counter` is a variable name. You could choose a different name, but it should help make the code clear.

    The counter values must match the indexes in the array. In this example, there are seven names, so the indexes run from `0` to `6`.
