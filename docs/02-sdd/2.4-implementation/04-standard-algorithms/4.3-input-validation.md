# Input Validation

!!! info "What you need to know"

    You must be able to describe, exemplify and implement the standard algorithm for input validation.

## What is input validation?

**Input validation** checks whether an input meets a rule before the program uses it.

| Check | Example rule |
| --- | --- |
| Type | A quiz score must be a whole number. |
| Range | A percentage must be between 0 and 100 inclusive. |
| Length | A password must contain at least six characters. |

Passing a validation check means the value meets the rule. For example, `14` may be within the allowed age range even if the person entering it is actually 15.

## The conditional-loop pattern

Read the first value before the loop. While the value is invalid, display an error and read a new value. The loop checks the new value before deciding whether to repeat. A valid first input skips the loop body.

**Algorithm**

```text
1 Get a value from the user
2 Validate the value
3 Use the accepted value
```

**Refinement**

```text
2.1 Start conditional loop while the value is invalid
2.2     Display an error message
2.3     Get a new value from the user
2.4 End conditional loop
```

## Range check with one boundary

This example accepts whole numbers greater than 15. The smallest accepted value is 16.

```python linenums="1"
user_input = int(input("Enter a whole number greater than 15: "))

while user_input < 16:
    print("Your number must be greater than 15.")
    user_input = int(input("Enter another whole number: "))

print("Number accepted.")
```

Entering `15` makes the condition true, so the program asks again. Entering `16` makes it false, so execution continues with the acceptance message after the loop.

## Input Validation Using Complex Conditional Statements

This range check accepts whole numbers from 1 to 10 inclusive. The loop repeats if either half of the `or` condition is true.

```python linenums="1"
user_input = int(input("Enter a whole number from 1 to 10: "))

while user_input < 1 or user_input > 10:
    print("Your number must be from 1 to 10 inclusive.")
    user_input = int(input("Enter another whole number: "))

print("Number accepted.")
```

Inputs `1` and `10` are accepted. Inputs `0` and `11` are rejected, and the program asks again.

!!! note "Both range checks assume whole-number input"

    If the user enters text such as `hello`, `int()` raises a `ValueError` before the range check can run. This can happen on the first input or on a retry. To handle text, the program would need to handle the failed conversion and ask again.

When testing a range check, include the valid boundary values and the values immediately outside them. [Test Data and Test Tables](../../2.5-testing/01.md)

## Login example

This classroom example uses a conditional loop to allow up to three tries. The username and password are strings. Use `==` to test whether the entered string matches the expected one. The `and` means both comparisons must be true.

```python linenums="1"
username = "user1"
password = "pass1"
attempts = 0
account_access = False

while attempts < 3:
    user_username = input("Please enter your username: ")
    user_password = input("Please enter your password: ")

    if user_username == username and user_password == password:
        print("Username and Password Accepted")
        account_access = True
        break

    attempts = attempts + 1
    if attempts < 3:
        print("Incorrect, please try again")

if not account_access:
    print("Too many attempts. Account locked. Please try later")
```

If both strings match, the program marks access as granted and `break` exits the loop. If either string differs, the failed-attempt counter increases. After three failures, the loop ends and the program displays the lockout message. The lockout applies to this run of the example.
