# Test Data and Test Tables

!!! info "What you need to know"

    You should be able to identify normal, extreme and exceptional test data, choose examples for a given program, and use them in a test table.

Testing checks whether a program behaves as its requirements say it should. Start by identifying what the program should accept and what it should do with invalid input.

## Choosing test data

Suppose a number-guessing game accepts whole numbers from **0 to 10 inclusive**. If a guess is outside that range, the program displays an error message and asks for another guess.

| Type | What it tests | Example |
| --- | --- | --- |
| **Normal** | A valid value within the range | `5` |
| **Extreme** | A valid value at one of the boundaries | `0` or `10` |
| **Exceptional** | An invalid value the program should reject | `-1` or `11` |

Test both valid boundaries and the values immediately outside them. This helps you catch mistakes such as accidentally rejecting `0` or accepting `11`.

## Writing a test table

Put one specific input in each row. Write the expected result before running the test. If the table asks for an actual result, record what the program did after running it and compare the two results.

| Test data | Type | Expected result |
| --- | --- | --- |
| `5` | Normal | Accept the guess and check it against the secret number. |
| `0` | Extreme | Accept the guess and check it against the secret number. |
| `10` | Extreme | Accept the guess and check it against the secret number. |
| `-1` | Exceptional | Display an error message and ask for another guess. |
| `11` | Exceptional | Display an error message and ask for another guess. |

This table tests whether a guess is accepted. To test the game's feedback for a correct or incorrect guess, use a known secret number so you can predict the result.

## Try it

A program asks the user to enter a result from a six-sided die. It accepts whole numbers from 1 to 6 and displays an error for any value outside that range. Write a test table with one normal value, two extreme values and one exceptional value.

??? example "Example answer"

    | Test data | Type | Expected result |
    | --- | --- | --- |
    | `3` | Normal | Accept the result. |
    | `1` | Extreme | Accept the result. |
    | `6` | Extreme | Accept the result. |
    | `7` | Exceptional | Display an error message. |

When a task gives you specific test data, use those values in your test table.
